# Security Policy

## Supported versions

Nur die aktuelle Version im `main`-Branch wird mit Sicherheitsupdates versorgt.

## Schwachstellen melden

Bitte verwende die private Schwachstellenmeldung beziehungsweise einen privaten
Security Advisory dieses GitHub-Repositories. Falls diese Funktion nicht
verfügbar ist, eröffne ein Issue ohne technische Details und bitte um einen
privaten Kontaktweg.

Veröffentliche keine Exploits, schädlichen URLs, personenbezogenen Daten oder
echte Malware in Issues, Pull Requests oder Testdateien. Eine gute Meldung
enthält betroffene Version, reproduzierbare Schritte, erwartetes Verhalten und
eine Einschätzung der Auswirkung.

WebSafe ist eine zusätzliche Browserschutzschicht und kein Ersatz für Safe
Browsing, Betriebssystemupdates oder einen Virenscanner.
