# Chrome Web Store assets

Upload the following files in the **Store listing** tab of the Chrome Web Store
Developer Dashboard:

- `websafe-store-icon-128.png` as the 128 × 128 store icon.
- The five JPEG files in `screenshots/` as the listing screenshots, in filename
  order.

Every screenshot is 1280 × 800 pixels and uses 24-bit RGB without an alpha
channel. The files in `screenshot-sources/` are reproducible local HTML sources
for the composed screenshots and are not uploaded to the store.
